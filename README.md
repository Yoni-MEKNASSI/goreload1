Go-Reloaded 🚀

Un programme en Go qui lit un fichier texte, corrige la ponctuation, applique des modifications sur les mots et enregistre le résultat dans un nouveau fichier.

📋 Fonctionnalités

Convertisseur : (hex) et (bin) convertissent les nombres en décimal.

Casse : (up) passe en majuscules, (low) en minuscules, (cap) met une majuscule au début.

Grammaire : Remplace a par an devant une voyelle ou un h.

Ponctuation : Ajuste automatiquement les espaces autour des points, virgules, etc.

🚀 Utilisation

Exécute la commande suivante dans le terminal :

go run . sample.txt result.txt


sample.txt : le fichier texte contenant le texte d'origine.

result.txt : le fichier généré avec le texte corrigé.
